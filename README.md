1. Як я зрозумів продукт — 5 пунктів
1. Це вебплатформа для керування продажами через AI-агентів, спочатку для KeyCRM: до 100 бізнесів, по 1–30 менеджерів. Власник керує задачами й дозволами, менеджер бачить свої ліди, оператор підтримує платформу з журналюванням доступу.
2. Можливості додаються поступово: аналіз і звіти → пропозиції змін → підтверджене виконання → обмежена автоматизація → коучинг, перебудова воронок і діалоги з клієнтами.
3. Агенти пропонують, виконавці діють. Між ними — політика прав, підтвердження точного набору змін, ліміти й аварійна зупинка. Запис проходить через свіже читання, порівняння, виконання та перевірку результату.
4. Безпека важливіша за завершення дії: ізоляція тенантів через RLS, маскування персональних даних, шифрування секретів, відмова при невизначеності. Видалення, фінансові зміни, закриття угод і зміни користувачів заборонені.
5. Платформа продає підписку й сама оплачує LLM. Метрики рахує код; модель потрібна для тексту та суджень. Кожен виклик проходить через app/llm/, бюджет, квоту, маршрутизацію і журнал вартості. «Навчання» означає підтверджувану базу знань, без донавчання моделей.
